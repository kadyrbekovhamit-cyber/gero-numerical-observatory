01

Declare the contract

Batch operations act on independent examples along the last feature axis. Check partitioning, permutation, duplication and rank changes. Reductions across the batch have a different contract.

f(concat(x, y)) ≈ concat(f(x), f(y))
02

Keep the mathematics honest

Probabilities must be finite and strictly within [0, 1]. Their sum uses a dtype-specific tolerance. A fully masked row returns exactly zero. LayerNorm variance includes epsilon.

Var(normalized) ≈ v / (v + ε)
03

Compare independent paths

Run identical graphs in ONNX Runtime and official ReferenceEvaluator. Check algebraic graph variants and analytic NumPy float64 formulas. Agreement alone is insufficient; matching NaN outputs fail.

NaN == NaN is never a passing result
04

Preserve the evidence

Download the original graph, inputs and SHA-256 manifest. Observations retain backend versions, output hashes, exact tolerances and session settings. Repeated identical observations are deduplicated.

python -m gero_stability.cli replay ARTIFACT_DIR

A bounded, reproducible scope.

This build measures CPU execution on seeded synthetic graphs using opset 19 / IR 10. QuantizeLinear and DynamicQuantizeLinear are excluded. DequantizeLinear remains covered. CUDA, model-level accuracy and global batch metrics are outside this run.

Float64 formulas are diagnostic checks, not arbitrary-precision proofs. A passing finite sample does not certify every possible input.
