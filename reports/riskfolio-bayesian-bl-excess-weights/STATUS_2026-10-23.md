# Status supplement — 23 October 2026

Authors: Xamit Kadirbekov and Daniyal Kadirbekov (GERO). AI-assisted investigation and writing.

This deposit preserves the initial tested proposal at commit bf6ee21bda17ef91a895726955c36d187bbc04aa. Its weight formula is `inv(delta * cov) @ (mu.T - rf)`, retaining the alpha included in the returned expected return when const=True. The four archived first-order-condition regressions pass on this version (rechecked 23 October in the isolated real-function harness).

After the report was written, upstream maintainer dcajasn changed the PR branch in commit 700fc19ee6955ed9d0e43623c500898ace22371d (22 October, 18:41:35 UTC) to `inv(delta * cov) @ Pi_blb`. That removes the rf contribution but also omits alpha from the directly returned weights. The archived tests run against this current source yield 2 passed / 2 failed: the two const=True cases have maximum stationarity residual 0.002, matching the largest supplied alpha.

This is a difference in the proposed weight contract. Our tests compare against the complete returned expected excess return, including alpha. The maintainer's formula instead uses the factor-prior contribution alone. The intended alpha convention needs clarification with the maintainer; we do not claim that this interpretation has been accepted. The original rf issue and the treatment of alpha are distinct.

PR #266 remains OPEN as checked 23 October. No merged or released correction is claimed. Neither run loaded the full Riskfolio package or its compiled extension. The ZIP is the unchanged evidence archive published on 22 October; its embedded report and tests refer to the initial proposal, not the later branch head.
