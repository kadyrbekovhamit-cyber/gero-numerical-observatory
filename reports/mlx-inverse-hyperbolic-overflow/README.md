# Finite Values, Missing Derivatives: MLX arcsinh and arccosh

Authors as published: Xamit Kadirbekov. First publication: 2026-09-10.

At float16 x=1000, arcsinh and arccosh return finite values but zero derivatives. A normalized real-derivative patch passes 518 native comparisons across four dtypes; GPU and speed are untested.
