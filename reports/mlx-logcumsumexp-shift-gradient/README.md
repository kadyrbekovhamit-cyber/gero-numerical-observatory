# Same Inputs, Wrong Weights: MLX logcumsumexp Gradients at Large Offsets

Authors as published: Xamit Kadirbekov. First publication: 2026-09-10.

At two equal float32 inputs of 100000000, MLX returns gradient [1,1] instead of [0.5,0.5]. An isolated CPU study separates a new VJP prototype from an already reported exp limitation.
