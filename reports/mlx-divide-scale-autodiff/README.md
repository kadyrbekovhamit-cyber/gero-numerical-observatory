# Same Ratio, Wrong Derivative: MLX Division at Extreme Scales

Authors as published: Xamit Kadirbekov. First publication: 2026-09-10.

For C/(C*t), the derivative at t=1 must remain −1. MLX returns zero or negative infinity at extreme scales. A research patch passes 1328 native comparisons, plus 1886 compatibility checks.
