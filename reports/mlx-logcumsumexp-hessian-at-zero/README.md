# Missing Curvature: MLX logcumsumexp at a Zero Incoming Gradient

Authors as published: Xamit Kadirbekov. First publication: 2026-09-10.

A smooth x²/2 example returns second derivative 0 instead of 1. A research C++ prototype passes 477 checks; GPU and large-tensor performance remain untested.
