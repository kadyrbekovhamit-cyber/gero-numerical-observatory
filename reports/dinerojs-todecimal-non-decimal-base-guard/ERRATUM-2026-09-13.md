# Archival correction — 13 September 2026

The original verification paragraph incorrectly says that both 250/240 and 25/20 are exactly representable in binary floating point.

250/240 = 25/24 has denominator 24 = 3 × 2³ in lowest terms, so its binary expansion is not finite. By contrast, 25/20 = 5/4 is exactly binary-representable.

The independent oracle is exact rational arithmetic. For the documented custom currency with base 240 and amount 250, the exact value is 25/24, while the returned decimal string "1.10" denotes 11/10. Their difference is 7/120, so the reported incorrect formatting is not a rounding ambiguity. The expected contract response for the non-decimal currency remains rejection.

This correction changes that verification sentence, not the reported reproducer, patch, original test results or scope. No numerical suite was rerun. The original article files are preserved byte for byte as historical evidence; read them together with this correction. Archived upstream status is dated and has not been rechecked for this deposit.
