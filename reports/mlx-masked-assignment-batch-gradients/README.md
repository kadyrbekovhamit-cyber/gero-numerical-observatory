# An Unused Value Gets a Gradient: MLX Masked Assignment

Authors as published: Xamit Kadirbekov. First publication: 2026-09-09.

MLX mapped boolean assignment routes gradients across batch examples. A local C++ patch passes 19 scenarios and 255 checks; explicit loops and actual-forward finite differences agree.
