# MoneyPHP loses largest-remainder ordering above float precision

Authors as published: Xamit Kadirbekov. First publication: 2026-09-05.

An accepted 7-quadrillion-unit amount makes two exact residuals collapse to zero in binary64, assigning the final unit to the wrong share.

This article was already archived in the 45-item GERO collection (https://doi.org/10.5281/zenodo.22683900). This individual record provides a separate citation; it is not a new finding or a new experiment.
