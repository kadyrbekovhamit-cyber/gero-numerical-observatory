# A Smooth Polynomial, a NaN Hessian: MLX cumprod at Zero

Authors as published: Xamit Kadirbekov. First publication: 2026-09-09.

MLX returns NaN second derivatives for a smooth cumulative-product polynomial at zero. A division-free C++ prototype passes 57 local scenarios, with an explicit O(N log N) cost.
