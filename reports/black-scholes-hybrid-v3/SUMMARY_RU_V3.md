# Следующий результат: Black–Scholes v3

**Хамит Кадырбеков и Даниял Кадырбеков. 26 сентября 2026 года.**

Новый численный алгоритм рассчитывает ту же модель в **4,58 раза быстрее v2**
на новой зафиксированной синтетической выборке. Среднее время вызова внутри
медианного измерительного пакета: **90,14 → 19,67 микросекунды**.

- **480 новых случаев**, все заранее заданные критерии цены и логарифма пройдены.
- Эталон сошёлся при 100/180 десятичных знаках во всех случаях; ещё **12**
  проверок через высокоточный интеграл прошли успешно.
- **604 старых примера** использованы отдельно для разработки, не выданы за
  новую проверку. Прошли **28 тестов**.
- В 412 из 480 случаев работают быстрые аналитические выражения; в 68 —
  прежний интегратор. В последней группе новый интерфейс примерно на 3% медленнее.
- На 426 ценах, не округляющихся в ноль, v3 ближе к эталону, чем v2, в
  **76** случаях, дальше в **99**, с равной ошибкой в **251**. Это сохранение
  заданных допусков, а не обещание одинаковой или лучшей точности в каждой точке.
- Максимальная относительная ошибка **нормальных** цен — около **3,12e-13**.
  Для мельчайших subnormal чисел этот показатель не применим: даже правильное
  округление иногда даёт относительную ошибку 82%. Полные ограничения сохранены.

Суть: специальные формулы для точного ATM, малой волатильности и хвостов;
обычная формула допускается после эвристической проверки устойчивости;
остальные случаи передаются неизменённому v2. Для рядов выведены оценки
остатка в точной арифметике. Это не оценка всех ошибок машинного вычисления.

BSM-модель не изменена. Улучшения предсказаний рынка, доходности торговли,
новизны метода или готовности к production не заявлены. Участие ИИ в
математике, коде, эксперименте и тексте раскрыто; независимой человеческой
рецензии ещё нет. Даниял указан соавтором и ответственным за дальнейшую
программную часть, без заявления о его независимой проверке текущего кода.

Полный вывод: `TECHNICAL_NOTE_V3.md`. Протокол: `EXPERIMENT_V3.md`.
Доказательства: `evidence/benchmark-v3.json`, `evidence/python-timing-v3.json`,
`evidence/freeze-v3.json`. Исходные публикации v2 остаются без изменений.

Вычисления выполнялись последовательно через общий one_worker, одним
численным CPU-потоком, без GPU. Скорость native C++ не измерялась.
